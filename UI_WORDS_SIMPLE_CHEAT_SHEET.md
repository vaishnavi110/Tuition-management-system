# UI Words Cheat Sheet & Vocabulary Guide
## Tuition Management System (Academy Portal)

This document is the official copy reference guide for all user-facing screens, buttons, tooltips, notifications, and modals.

---

### Golden Rule
> **"Would a parent or teacher say this out loud?"**  
> If no, change it to simple words like *class, teacher, student, parent, fees, payment, attendance, homework*.

---

### Core Terminology Mappings

| Change This ❌ | To This ✅ | Reason / Context |
| :--- | :--- | :--- |
| **Tutor / Instructor / Staff** | **Teacher** | Standard terminology for clients, teachers, and parents. |
| **Session / Virtual Classroom** | **Class** | A parent understands "class", not "session" or "telemetry". |
| **Auto-attendance** | **Attendance recorded** | Plain English, removes surveillance/technical tone. |
| **Present (Auto-detected)** | **Present — recorded** | Clear and definitive attendance status. |
| **Meeting link opened** | **Join time recorded** | Clearer than technical telemetry wording. |
| **Fee bill / Fee statement / Proforma invoice** | **Monthly fee bill** | Standard client and parent language. |
| **Settlement** | **Payment** | Simple, everyday accounting word. |
| **Salary / Compensation / Earnings / Payout** | **Teacher payment** | One clear term for teacher compensation. |
| **Billing rate / Hourly rate** | **Fee rate** *(for student)* / **Teacher rate** *(for teacher)* | Explicitly states whose rate is being displayed. |
| **₹400/hr** | **₹400 per hour** | Spelled out for professional presentation. |
| **Institute cut / Institute margin** | **Academy share** | Professional, standard academy business language. |
| **NO DUES / PAYMENT DUE** | **No amount due / Payment due** | Calm title case; avoid aggressive all-caps. |
| **₹0 charged** | **No charge** | Natural English. |
| **Access Your Portal** | **Sign In** | Standard, recognizable action button. |
| **Verifying...** | **Signing in...** | Matches user action precisely. |
| **Save & Verify Class Log** | **Save class log** | "Verify" sounds too technical for everyday use. |
| **Coming Soon in v1.0 (Milestone 2)** | **Planned for later** | Removes internal developer release jargon. |
| **Homework notebook photo** | **Photo of completed work** | Immediately clear for parents and students. |

---

### Words Strictly Removed From Client-Facing Screens

Do **not** use the following developer, tech-stack, or marketing buzzwords in UI labels, subtext, or tooltips:
- ❌ *Instant*
- ❌ *1-Click*
- ❌ *Zero* (as buzzword, e.g. "Zero hassle")
- ❌ *100%* (in promotional contexts)
- ❌ *Smart*
- ❌ *Effortless*
- ❌ *Master Console*
- ❌ *Central command center*
- ❌ *Core engine*
- ❌ *Chaos*
- ❌ *Relatives*
- ❌ *PostgreSQL / SQL*
- ❌ *token*
- ❌ *sessionId*
- ❌ *API / Telemetry*

---

### Tone & Message Guidelines

Keep messages calm, professional, and clear. Avoid exclamation marks, hype words, and excessive emojis.

- ❌ `✅ Profile updated successfully!`  
  ✅ `Profile updated.`
- ❌ `🎉 Post-class log saved! 1.5 hrs verified for billing.`  
  ✅ `Class log saved. 1.5 hours added to the fee bill.`
- ❌ `🚀 Meeting launched! Tracking telemetry timestamp...`  
  ✅ `Class joined. Join time recorded.`
- ❌ `✅ Homework notebook uploaded and submitted for teacher review!`  
  ✅ `Work submitted for teacher review.`
